# Key decisions
I decided to go with EsBuild to bundle the fastify server. The electron app (client) is primary distributed to the end users with the fastify server wrapped as a js file in resources. The electron app, inside its node environment, would run that server file. 
All things we need to do in the user machine will be mediated by the preload script of electron. Renderer will take care of GUI. The server will take care of the business code.
